# Taste 产品栈文档
> 记录时间：2026年7月13日

---

## 一句话定位

> 贴在手机背后的外置AI执行器——让任何Android手机获得一个看不见的、不可被检测的本地AI agent。

---

## 产品形态

| 属性 | 定义 |
|------|------|
| 形态 | 信用卡大小，可贴手机背后，可拆卸 |
| 通信 | 5GHz WiFi（卡片创建热点，手机直连） |
| 系统 | Rooted Android 或 Linux（完全自由） |
| 定位 | 便携口袋服务器 / 外置AI执行层 |
| 价格目标 | 便宜，让更多人用得起 |

---

## 核心价值主张

**为什么不直接在手机上跑？**

| 问题 | 手机上跑 | 卡片跑 |
|------|---------|--------|
| 反作弊检测 | 进程可见，易被检测 | 外部设备，注入看似人类操作 |
| 性能 | Agent + 游戏抢资源 | 卡片专跑AI，手机专跑游戏 |
| 自由度 | 沙盒限制，App Store审查 | Rooted，跑任何模型任何软件 |
| 身份隔离 | 和主账号绑定 | 独立设备，操作不污染主手机 |

## 使用场景（PMF优先级排序）

### P0：手游AI外挂（最强PMF）
- YOLO目标检测 → 坐标回传 → 模拟点击
- 市场大，付费意愿强
- 现有方案需要root手机（高风险），卡片方案几乎无法被检测

### P1：Openomnibot 手机自动化
- 卡片运行Openomnibot agent
- 看手机屏幕 → 决策 → 操作
- 游戏自动化、任务挂机、抢购秒杀

### P2：本地AI推理（无审查）
- 本地SD图像生成（无内容限制）
- 本地LLM（无审查）
- 模型可随时替换

### P3：通用Android自动化
- 自动签到、积分任务
- 社交媒体自动化
- 工作流批处理

## 技术栈

### 硬件层
```
[ 卡片硬件 ]
  CPU/NPU  : ARM + NPU（跑YOLO/小LLM）
  WiFi     : 5GHz，支持AP模式（创建热点）
  存储     : eMMC（存模型、系统）
  电池     : 小型锂电（或从手机取电）
  OS       : Rooted Android / Linux
```

### 屏幕采集 Pipeline（手机侧）
```
MediaProjection API
    → MediaCodec（H.264硬件编码，<5ms）
    → UDP Socket
    → 卡片接收
```
- 分辨率：640×480 或 720p（YOLO够用，带宽小）
- 帧率：15-30fps（AI处理不需要60fps）
- 参考实现：scrcpy（开源，已验证）

### 传输层
```
协议   : UDP（低延迟，丢帧可接受）
网络   : 5GHz WiFi Direct（卡片作热点，手机直连）
带宽   : 3-8Mbps（720p@30fps H.264）
延迟   : 单程 5-15ms
```

### AI推理层（卡片侧）
```
YOLO     : 目标检测，NPU加速，10-30ms/帧
Openomnibot : 屏幕理解 + 决策agent
本地LLM  : Phi-3 mini / Qwen 1.5B（基础对话）
本地SD   : 图像生成推理（无LoRA训练）
模型管理 : 可热替换，不经过任何审批
```

### 控制注入层（回到手机）
```
方式1: ADB over WiFi
  - adb connect 192.168.x.x
  - 完整控制权：点击、滑动、输入、截图
  - 需用户一次性开启开发者模式

方式2: Accessibility Service
  - 手机装一个App，开启辅助功能权限
  - 合法，Google允许
  - 可读屏幕内容 + 模拟操作
```

### 完整延迟预算
```
手机截屏    5ms
H.264编码   5ms
WiFi传输   10ms
卡片解码    5ms
AI推理     20ms  ← YOLO on NPU
指令回传    5ms
注入执行    5ms
─────────────────
总计      ~55ms   ✓ 游戏可用
```

## 关键假设（待验证）

1. 5GHz WiFi Direct延迟是否稳定在15ms以内？
2. 卡片形态的NPU能否在20ms内完成YOLO推理？
3. ADB over WiFi稳定性是否满足长时间自动化需求？
4. MediaProjection + UDP pipeline实际延迟是多少？
5. 手游反作弊系统是否检测外部ADB注入？
