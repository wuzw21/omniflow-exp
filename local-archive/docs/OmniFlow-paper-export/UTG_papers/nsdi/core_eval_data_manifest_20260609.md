The paper-facing result version is `latest_results_index/`. The offline replay
source-evidence version is `offline_source_runlog_pool/`. Do not cite or
aggregate any older runtime directory directly. If a raw result, run log,
checkpoint, or baseline output is needed for audit, follow the absolute paths
stored in `all_latest.jsonl`, `all_success_source_runlogs.jsonl`, and their
`referenced_paths.json` files. Those referenced paths are provenance for these
two current indexes, not separate result versions. Treat every sibling retry,
pre-fix directory, and older accepted snapshot as superseded unless it is
