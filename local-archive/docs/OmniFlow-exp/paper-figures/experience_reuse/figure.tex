(b) Historical paths provide successful actions and source states that can be segmented into parameterized Functions. Intuitive transfer reasoning denotes learned cross-device action mapping: the intended action remains the same while the target layout changes. Reliable mappings enable direct execution, while uncertainty or failure returns control to the Planner/VLM. Reuse resumes when an applicable state is reached. The objective is to reduce VLM calls while preserving task success; net latency also depends on mapping and recovery overhead.}
